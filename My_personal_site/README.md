# Kalyan K R — Personal Portfolio

A responsive single-page portfolio website for a Python Backend Developer.

## Files
- index.html — portfolio content
- styles.css — design and responsive layout
- script.js — mobile navigation and reveal animations

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the LinkedIn URL with your profile.
3. Replace the GitHub URL with your profile.
4. Add a profile photo if desired.
5. Review the experience dates and project wording against your final resume.

## Run locally
Open `index.html` directly in a browser, or use a simple local server:

`python -m http.server 8000`

Then open `http://localhost:8000`.
